# HellSinkerGLWallPaper

[HellSinker](https://store.steampowered.com/app/1067720/Hellsinker/)のメニュー画面

- `THE GRAVEYARD`
- `DRIVING FACTOR`
- `A THING LEFT BEHIND`
- `MEMENTO`

をAndroidのライブ壁紙として再現するアプリ

大昔(2013年頃?)に某所でも配布していたものになります。どこかしら不具合があるかも。

**ダウンロード**: [app-release.apk](https://github.com/106-/HellSinkerWallPaper/releases/latest/download/app-release.apk)
